#001

E-Commerce Platform Security Audit

3 Critical 5 High 2 Medium

Context: A mid-size Indian e-commerce platform selling fashion products. ~10,000 daily users.

Key Findings: SQL injection in product search endpoint allowing database extraction. IDOR in order history allowing users to view other customers' orders. Weak session management — no HTTPOnly/Secure flags on cookies.

Impact: Potential data breach of 50,000+ customer records including addresses and phone numbers.

Remediation: Parameterized queries implemented, access controls added, session cookies hardened.

#002

EdTech Startup VAPT

1 Critical 3 High 4 Medium

Context: Fast-growing EdTech startup with web + mobile apps. 25,000+ registered students.

Key Findings: Server-Side Request Forgery (SSRF) in profile image upload. Broken authentication — JWT tokens not validated on server side. Mass assignment vulnerability in user update API.

Impact: SSRF could be chained to access internal AWS metadata endpoint. Authentication bypass would allow account takeover.

Remediation: Input validation on image URLs, JWT validation middleware added, API input sanitization.

#003

Local Business Directory

0 Critical 2 High 6 Medium

Context: A local business listing website for Tier-2 cities in India. Built on WordPress.

Key Findings: Stored XSS in business review section. CORS misconfiguration allowing cross-origin data access. Outdated WordPress plugins with known CVEs. Directory listing enabled on server.

Impact: XSS could steal admin session. Outdated plugins have public exploits available.

Remediation: Input sanitization for reviews, CORS header configuration, plugin updates, server hardening.
